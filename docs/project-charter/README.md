# Carta proiectului (Project Charter)

**Carta** este documentul de inițiere al proiectului. Ea fixează:
- de ce facem proiectul și ce livrăm;
- ce intră și ce nu intră în proiect;
- cine ce rol are;
- calendarul, riscurile și criteriile de succes.

Cursul nu o cere explicit. Este instrumentul Project Manager-ului (D) prin care echipa și coordonatorul cad de acord asupra proiectului la Ședința 3. Secțiunile despre roluri, metodologie și plan se refolosesc în Raportul Tehnic.

| Fișier | Conținut |
|---|---|
| [Carta_Proiectului.docx](Carta_Proiectului.docx) | documentul Word, în formatul șablonului UNITBV |
| [Carta_Proiectului.pdf](Carta_Proiectului.pdf) | exportul PDF |
| [src/](src/) | sursele Markdown; **aici se editează** |
| [document.toml](document.toml) | titlul, coperta, ordinea secțiunilor |

**Responsabil:** D.

**Revizuire:**
1. Toată echipa o revizuiește în S0.
2. După revizuire, echipa o semnează în tabelul de aprobare.

**Actualizare:** carta se actualizează doar la schimbări de domeniu sau de calendar, aprobate de echipă. Fiecare versiune nouă se trece în istoricul din documentul Word.

**Regenerare:** `bash tools/docgen/build.sh charter` (detalii în [tools/docgen/README.md](../../tools/docgen/README.md)).
