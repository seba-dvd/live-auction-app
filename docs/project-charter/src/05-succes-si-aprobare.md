# Criterii de succes și aprobare

## Criterii de succes

Proiectul este considerat reușit dacă:

- toate cerințele obligatorii ale disciplinei sunt îndeplinite și demonstrate;
- Raportul Tehnic: Proiectare este predat la termen și acoperă metodologia, rolurile, structura bazei de date și diagramele de clase și use case;
- scenariul de demonstrație rulează fără intervenții manuale, cu două browsere și în cloud:
  1. înregistrare;
  2. creare licitație;
  3. licitare în paralel;
  4. notificare „depășit”;
  5. prelungire anti-sniping;
  6. închidere automată;
  7. plata câștigătorului și încasarea vânzătorului;
- testele automate pentru fluxurile critice și colecția Postman trec în CI;
- fiecare membru are contribuții vizibile în componenta proprie și prezintă partea sa la evaluare.

## Criterii de acceptanță ale livrabilelor

- **Funcționalități:**
  - fiecare user story este acceptată de Product Owner (A) la sprint review, pe baza criteriilor „Dat fiind / Când / Atunci” din backlog;
  - fiecare sarcină tehnică respectă Definition of Done: compilează, testele trec, CI-ul e verde, contractele și colecția Postman sunt actualizate, nu conține secrete, rulează în Docker Compose.
- **Documente:** sunt revizuite de cel puțin un alt membru înainte de predare.
