- ADR – Architecture Decision Record (înregistrarea unei decizii de arhitectură);
- API – Application Programming Interface (interfață de programare a aplicațiilor);
- BCrypt – funcție de hash adaptivă pentru parole;
- CI/CD – Continuous Integration / Continuous Delivery (integrare și livrare continuă);
- CORS – Cross-Origin Resource Sharing;
- CRUD – Create, Read, Update, Delete;
- DDL – Data Definition Language;
- DTO – Data Transfer Object (obiect de transfer al datelor);
- ER – Entitate-Relație;
- GHCR – GitHub Container Registry;
- HS256 – HMAC cu SHA-256 (algoritm de semnare a tokenurilor JWT);
- HTTP(S) – HyperText Transfer Protocol (Secure);
- IESC – Inginerie Electrică și Știința Calculatoarelor;
- JDBC – Java Database Connectivity;
- JPA – Jakarta Persistence API;
- JSON – JavaScript Object Notation;
- JWT – JSON Web Token;
- MoSCoW – Must, Should, Could, Won't (metodă de prioritizare);
- MVP – Minimum Viable Product (produs minim viabil);
- RACI – Responsible, Accountable, Consulted, Informed;
- REST – Representational State Transfer;
- RFC – Request for Comments;
- SPA – Single Page Application;
- SQL – Structured Query Language;
- STOMP – Simple Text Oriented Messaging Protocol;
- UML – Unified Modeling Language;
- UTC – Coordinated Universal Time;
- UUID – Universally Unique Identifier;
- VM – Virtual Machine (mașină virtuală).
